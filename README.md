# BUTTER — сайт кофейни (Махачкала)

Одностраничный сайт кофейни BUTTER: спешелти кофе, завтраки весь день и авторские напитки.

- Адрес: просп. Расула Гамзатова, 14, Махачкала
- Часы работы: ежедневно 10:00–20:00
- Телефон: +7 (988) 277-71-92

## Структура

- `index.html` — разметка и контент (меню, галерея, контакты)
- `styles.css` — стили: тёмный hero с aurora-подсветкой, spotlight-карточки, 3D-карусель, giant-типографика, зерно плёнки
- `script.js` — интерактив: параллакс-сцена с парящими фото, 3D coverflow-карусель, tilt-карточки с бликом, бегущая строка, магнитные кнопки, кастомный курсор, частицы «кофейные зёрна»
- `favicon.svg`
- `images/` — фотографии (см. ниже)

## Изображения

Папку `images/` нужно загрузить вручную: GitHub → **Add file → Upload files** → перетащить файлы:
`latte.jpg`, `waffles.jpg`, `waffles-top.jpg`, `sandwich.jpg`, `breakfast.jpg`, `drink-cherry.jpg`, `toast.jpg`, `menu-drinks.jpg`, `menu-food.jpg`.

## Публикация (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)`.
Сайт будет доступен по адресу: `https://qqniqq.github.io/butter/`

Технологии: чистый HTML/CSS/JS, без зависимостей и сборки.
